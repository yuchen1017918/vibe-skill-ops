🌱 大道至简（设计核心）

token × 质量 = 乘积最优，不是取舍。机制越多 → 加载越贵（token ↑）且走样越多（质量 ↓）= 双输；机制越少 → 加载便宜（token ↓）且执行越准（质量 ↑）= 双赢。

落地动作：合并 3 组重叠 skill（6→3）、契约层 ≤5 行（常驻减半）、一句话画像 + 默认路径化（15 秒锁定路由）、30 天未加载 → deprecated、证据消费（月报强制决策）。

🏗️ 四层组织路由（v1.1.0 结构整改）

从"按技术类型路由"改为按组织形态 + 开发模式路由——需求的第一性属性是"规模 + 谁主导"，不是语言：

L1 组织形态(团队/企业) → L2 开发模式(助手/全盘) → L3 四格场景 → L4 执行 skill
      ↕ 技术分类 hub 下移为二级索引（dev-core / dev-stack / dev-infra / dev-agent / dev-ai）

主流程四选一：dev-assistant（助手）/ quick-dev（团队·随手做）/ vibe-coding（单人 MVP）/ dev-team（企业·全盘）。

🗺️ 一句话画像

【组织】【主导】【类型】【技术】15 秒锁定 L1+L2；反驳只更新画像，不重走路由。

🎚️ 介入深度 L0-L4

dev-assistant 分档：答疑→指路→草稿→副驾驶→代驾；跨文件变更阻塞型确认。

🧭 复杂度 Triage

5 题是/否清单 L0/L1/L2；quick-dev 收编为执行器（5 项量化指标 + 转正钩子）。

📋 确认交互契约

阻塞/通知/批量三种确认，超时策略 + /focus 免打扰，根治确认疲劳。

⛔ 升降天花板

fallback 升级 ≤6 步硬限，第 3 步提示、第 6 步人工介入；5 分钟循环检测。

📡 证据消费

cost-agent 周报一句话洞察（走样 Top + Triage 误判）+ 月报强制决策三问。

🔗 合并审查

触发词重叠 >50% / 30 天未加载 / 一方总引用 → 合并候选；新增 skill 7 天冷静期。

💰 成本治理 + 知识萃取

token 周报 / ROI 看板；任务后自动 5 Whys 复盘，经验越用越聪明。

⚠️ 边界声明（读完不误解）

Vibe-Skill-Ops 是 一组 Markdown 文档（SKILL.md），不是可执行软件。没有后台进程、没有自带运行时。所有"自动触发""自愈"均指 Agent 加载 skill 后按文档约定执行；可靠性上限 = Agent 的指令遵循能力。它增强 Agent，但不依赖它 Agent 也能工作。
