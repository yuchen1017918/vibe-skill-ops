Vibe-Skill-Ops
运行在 Hermes Agent 上的自治理 Vibe Coding Skill 体系
v3.6 28 skills MIT License 三层路由 确认 SLA 知识萃取

📦 这是什么

Vibe-Skill-Ops 把 28 个开发技能组织成一套 三层渐进式目录，让 Agent 报个需求就能按路由走到成熟流程：先判复杂度（Triage 判定清单），再按类型路由（5 个 L2 分类），最后落到具体 skill（22 个 L3）。

它是 文档体系，不是软件——所有"自动"都是 Agent 按文档约定执行。增强，不依赖。

🧭 复杂度 Triage

5 题是/否判定清单，L0/L1/L2 分级，避免杀鸡用牛刀。

📋 确认交互契约

阻塞/通知/批量三种确认，超时策略 + /focus 免打扰，根治确认疲劳。

💓 心跳熔断器

CLOSED/OPEN/HALF-OPEN 状态机，子 Agent 失控自动兜底。

📡 经验召回

三维评分 + 过滤，只注入有效经验，防上下文污染。

🧠 知识萃取

任务/异常后自动 5 Whys 复盘，经验自动生长、越用越聪明。

💰 成本治理

token 周报 / 实时告警 / ROI 看板，观测者豁免防递归。

🔐 安全审计

提交前六维扫描，规则分级 + 误报反馈，防"狼来了"效应。

🪞 元治理

事件驱动的治理审查：冲突矩阵、fallback 环路检测、权限递归审计。

方式一：快捷提示词（推荐给用户使用）

把下面这段提示词复制发给你的 AI Agent，它会自动读取教程并完成安装：

https://yuchen1017918.github.io/vibe-skill-ops/Tutorial.md，帮我下载安装这个 vibe-coding skill 全家桶。

GitHub Pages 未启用时可用：https://raw.githubusercontent.com/yuchen1017918/vibe-skill-ops/main/Tutorial.md，帮我下载安装这个 vibe-coding skill 全家桶。

方式二：手动安装（3 步）

1
下载仓库 
git clone https://github.com/yuchen1017918/vibe-skill-ops.git /tmp/vibe-skill-ops
2
复制到 skills 目录 
mkdir -p ~/.hermes/skills
cp -r /tmp/vibe-skill-ops/vibe-coding-family ~/.hermes/skills/
3
验证 
find ~/.hermes/skills/vibe-coding-family -name SKILL.md | wc -l   # 应为 28

国内网络慢？git clone 加 ghproxy 前缀：git clone https://ghproxy.net/https://github.com/yuchen1017918/vibe-skill-ops.git /tmp/vibe-skill-ops

⚠️ 边界声明（读完不误解）

Vibe-Skill-Ops 是 一组 Markdown 文档（SKILL.md），不是可执行软件。没有后台进程、没有自带运行时。所有"自动触发""自愈"均指 Agent 加载 skill 后按文档约定执行；可靠性上限 = Agent 的指令遵循能力。它增强 Agent，但不依赖它 Agent 也能工作。
