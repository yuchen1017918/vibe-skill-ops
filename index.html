🎯 What problem does it solve?

Native Hermes Agent painAfter installing the family
You re-teach workflows every session; context swells with redundant instructions.Hub auto-routes to the right skill in seconds; mechanisms load on demand.
No security baseline — SQL injection, hardcoded secrets slip through.Three-layer defense: silent disciplines + commit gate + on-demand deep scan.
Cross-session context loss — "we did this before" forgotten.Dual-layer memory: project snapshots + experience/vulnerability libraries.
Quality depends on mood — no review, no gate.AI code review engine + dual-gate before commit.
Token waste — huge skill bodies always loaded.Progressive disclosure: ≤5-line contracts in context, full body on demand.
Non-intrusive: it is an enhancement, not a dependency. Uninstall or route-failure → falls back to plain Hermes Agent. No lock-in.

⚡ 3-Second Install

Paste this one line to your agent:

Please follow https://yuchen1017918.github.io/vibe-skill-ops/Tutorial.md, and download & install the Vibe-Skill-Ops skill family for me.

Or manually:

mkdir -p ~/.hermes/skills/vibe-coding-family
git clone --depth 1 https://github.com/yuchen1017918/vibe-skill-ops /tmp/vso
cp -r /tmp/vso/vibe-coding-family ~/.hermes/skills/
