# 多Agent权限规范（Agent Permissions）

**核心思想**：多Agent协作必须有清晰的职责边界与权限模型——**谁可以做什么、访问什么、修改什么**。
权限越清晰，越不会出安全事故（误删、越权改、密钥泄露）。

## 1️⃣ 角色与职责总览

| 角色 | 核心职责 | 可产出 | 不可产出 |
|------|----------|--------|----------|
| 👑 **主Agent**（PM/Tech Lead） | 指挥、审查、验收、决策、用户沟通 | 计划/审查报告/验收决定 | —（最高权限） |
| 📋 **spec-writer** | 规范、架构、AGENTS.md | SPEC.md / ARCH.md / AGENTS.md | 源代码、测试代码 |
| 💻 **coder** | 按规范实现代码 | 源代码、依赖配置 | 测试代码、规范变更 |
| 🧪 **tester** | 编写并运行测试 | 测试代码、测试报告 | 修改源码（除非授权） |
| 🔧 **bug-fixer** | 修复Bug、回归 | 修复代码、回归清单 | 重构、改测试预期（不说明理由） |
| 🤖 **外部AI编码器**（claude-code/codex/opencode） | 被委派编码 | 代码（需主Agent验证） | 直接提交、直接部署 |

## 2️⃣ 文件系统权限矩阵

| 路径 | 主Agent | spec-writer | coder | tester | bug-fixer |
|------|:-------:|:-----------:|:-----:|:------:|:---------:|
| `docs/dev-team/`（规范文档） | ✅ 读写 | ✅ 写 | ❌ | ❌ | ⚠️ 只读 |
| `src/` `app/`（源代码） | ✅ 读写 | ❌ | ✅ 写 | ⚠️ 只读 | ✅ 写（最小修改） |
| `tests/`（测试代码） | ✅ 读写 | ❌ | ⚠️ 只读 | ✅ 写 | ⚠️ 只读 |
| `agents/<自己>/`（自己工位） | ✅ 读写 | ✅ 写 | ✅ 写 | ✅ 写 | ✅ 写 |
| `agents/<别人>/`（他人工位） | ✅ 读写 | ❌ | ❌ | ❌ | ❌ |
| `.snapshots/`（共享快照） | ✅ 读写 | ⚠️ 只读 | ⚠️ 只读 | ⚠️ 只读 | ⚠️ 只读 |
| `.env`（密钥） | ✅ 唯一管理 | ❌ | ❌ | ❌ | ❌ |
| `package.json`/`requirements.txt` | ✅ 读写 | ❌ | ✅ 写 | ⚠️ 只读 | ⚠️ 只读 |

> ⚠️ 只读 = 可读取作参考，不可修改。
> 例外授权：主Agent 可在任务中显式授予临时写权限（如 tester 修测试、coder 补依赖）。

## 3️⃣ 命令权限分级（终端安全）

| 级别 | 命令示例 | 允许谁 | 说明 |
|------|----------|--------|------|
| 🟢 **安全** | `python` `pytest` `npm test` `git status` `git diff` `read_file` | 所有Agent | 读取/测试/构建 |
| 🟡 **受限** | `git commit` `git push` `pip install` `npm install` `rm <明确文件>` | 主Agent 授权后 | 需主Agent确认或任务内显式包含 |
| 🔴 **高危** | `rm -rf` `sudo` `mkfs` `dd` `DROP TABLE` `git push --force` | ❌ 仅主Agent，且必须用户确认 | 任何子Agent禁止 |
| 🟣 **敏感** | 读 `.env`、访问数据库生产库、调用付费API | ❌ 仅主Agent | 涉及密钥/生产/费用 |

**子Agent 默认权限**：🟢 安全级 + 任务内明确包含的 🟡 受限操作。
**主Agent 兜底**：任何子Agent请求高危/敏感操作 → 拒绝 + 上报用户。

## 4️⃣ 数据安全红线（不可逾越）

1. **密钥保护**：`.env` / API Key / Token 只由主Agent管理；子Agent禁止读取、禁止写入代码。
2. **硬编码禁止**：任何Agent不得把密钥/口令写进源代码或文档。
3. **生产数据**：子Agent禁止直接操作生产数据库（只能操作测试环境）。
4. **付费API**：子Agent调用付费API前必须经主Agent确认（成本控制）。
5. **敏感信息**：发现密钥泄露 → 立即停止 + 上报主Agent + 建议轮换。
6. **工位隐私**：子Agent只读写自己工位，不窥探他人工位（除非主Agent明确授权）。
7. **攻击性操作授权闸门**（v1.3 新增，借鉴 reverse-skill Scope Gate）：逆向/渗透/扫描/exploit 类操作，**行动前必查 4 问**（目标是谁的/范围明确吗/方法合规吗/报告给谁）——目标非用户自有或未明确授权 → **禁止执行**；只有授权目标（自己的应用/CTF 靶场/明确授权的系统）可进行。红线不是建议。

## 5️⃣ 权限授予与回收

```
授权流程：
1. 主Agent 在委派任务中显式声明："授予 <角色> <路径/操作> 的 <写/执行> 权限"
2. 授权范围最小化：只给本次任务需要的权限
3. 任务完成 → 权限自动回收（下次任务需重新授权）

回收规则：
- 任务结束即回收（默认）
- 违反权限 → 立即回收 + 记录到工位 EXPERIENCE.md
- 主Agent 可随时撤销任何子Agent的任何权限
```

## 5.1 审计日志（v1.1 新增 — 宪法代码化）

**目的**：所有文件写操作自动记录到 `.snapshots/audit.log`，越权可追溯。

### 审计日志格式
```markdown
# 文件操作审计日志 — <项目名>
| 时间 | Agent | 操作 | 目标 | 结果 | 授权来源 |
|------|-------|------|------|------|----------|
| 2026-08-06 15:30 | coder | WRITE | src/users.py | ✅ | 任务委派授权 |
| 2026-08-06 15:32 | tester | READ | src/users.py | ✅ | 只读默认 |
| 2026-08-06 15:40 | tester | WRITE | src/users.py | 🛡️ 拦截 | 无授权（越权） |
```

### 审计规则
```
1. 写操作（创建/修改/删除文件）→ 必须记审计
2. 拦截事件（越权/高危命令）→ 必须记审计（红标 🛡️）
3. 读操作 → 默认不记（量大）；敏感路径（.env/生产库）→ 必记
4. 审计日志本身 → 仅主Agent 可写/删（防篡改）
```

### 硬拦截联动
- 命令级：配合 `vibe-terminal-safe` 的 harden-shell.sh（自动记录 BLOCKED/WRITE）
- 文件级：主Agent 在委派时检查子Agent 文件操作是否符合权限矩阵（§2），
  不符合 → 拦截 + 记审计 + 回收权限

### 审计检查时机
- 每个 Phase 完成：主Agent 抽查审计日志
- 越权事件：立即检查 + 处置（§6）
- 项目结束：审计日志归档到 .snapshots/history/（保留 90 天）

## 6️⃣ 越权检测与处置

| 越权行为 | 检测方式 | 处置 |
|----------|----------|------|
| tester 修改源码 | 文件权限矩阵 + 代码审查 | 退回 + 警告 |
| 子Agent 读 .env | 命令日志 + 行为审查 | 立即停止 + 上报 |
| bug-fixer 大规模重构 | 改动行数超限（>50行） | 退回 + 要求最小修改 |
| coder 跳过测试直接交付 | 交付物审查 | 退回 + 要求走测试 |
| 子Agent 请求高危命令 | 命令白名单拦截 | 拒绝 + 上报主Agent |

**举报链**：子Agent发现其他Agent越权 → 记录证据 → 上报主Agent → 主Agent裁决。

## 7️⃣ 与全家桶衔接

| Skill | 协作关系 |

| `snapshot-notes` | 快照只读权限（子Agent）由本 skill 定义 |

## ⚠️ 核心原则

1. **最小权限**：只给任务需要的权限，用后即收。
2. **默认拒绝**：未明确授权的操作 = 禁止（子Agent）。
3. **单一密钥面**：密钥只经主Agent，永远不经过子Agent。
4. **审计留痕**：权限授予/越权事件记录到 `.snapshots/` 审计日志。
5. **安全优先**：权限冲突时，宁可不做，不可越权。

## 快速排障

| 症状 | 处理 |
|------|------|
| 子Agent 需要额外权限 | 走授权流程：主Agent 显式授予（最小化+限时） |
| 发现子Agent越权 | 记录证据 → 上报 → 处置（§6） |
| 密钥疑似泄露 | 立即停止 → 轮换密钥 → 审计工位/快照 |
| 权限模型太复杂 | 记住核心：子Agent 默认只读+任务内授权，敏感操作全归主Agent |
| 需要临时权限 | 主Agent 用"临时授权"标注，任务完成自动回收 |
